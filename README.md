# Grandeardfg Website

Professional responsive tourism website for **Grandeardfg**.

## Included
- Featured destinations
- Vacation packages with sample pricing
- Travel experience categories
- About section
- Testimonials
- Trip planning/contact form
- Responsive mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish with GitHub Pages
Upload all files to the root of the `grandeardfg` repository.
Then go to **Settings → Pages → Deploy from a branch → main / root → Save**.

Destination photography is loaded from Unsplash. Package names and prices are sample content and can be replaced with your actual offers.
